Fracture Protocol

A turn-based 8x8 containment stabilization puzzle game.

Core Loop:
Place module → Resolve grid → Hazards escalate → Pressure rises → Integrity falls → State updates → Repeat

Primary Player Goal:
Delay structural collapse long enough to complete containment cycles.

Design Pillars:
• Emotional containment visualization
• Deterministic simulation-friendly mechanics
• High readability mobile UI
